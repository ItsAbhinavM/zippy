# zippy

## How to run
1. Clone the repo
```
git clone https://github.com/ItsAbhinavM/zippy.git
```
2. Setup `.env` file, follow `.env.example` to fill out the required keys
```
LIVEKIT_URL= LiveKit Project URL
LIVEKIT_API_KEY= LiveKit Key
LIVEKIT_API_SECRET= LiveKit View Only Once Secret Key
GEMINI_API_KEY= LLM MODEL Key
DEEPGRAM_API_KEY= STT Key
CARTESIA_API_KEY= TTS Key
```
3. Run the project
```
docker compose up
```
